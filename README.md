# Gloss

**Английский ↔ русский — рядом с тем, что вы читаете.**

Переводчик для строки меню macOS. Выделите текст, дважды нажмите ⌘C —
перевод появится рядом с курсором.

## Возможности

- **Перевод без переключения приложений.** Двойное копирование, горячие клавиши
  или ручной ввод через иконку в строке меню.
- **Словарные карточки.** Транскрипция, части речи, варианты перевода, синонимы
  и примеры из Yandex Dictionary; озвучивание слова.
- **Перевод текста с экрана.** Выделите область — Gloss распознает текст
  с помощью Apple Vision и переведёт его. Подходит для изображений и текста,
  который нельзя скопировать.
- **Офлайн-перевод.** Apple Translation переводит текст на устройстве после
  загрузки языкового пакета и подстраховывает словарь, если тот недоступен.
- **Окно под себя.** Закрепление поверх приложений, изменение размера,
  выбор шрифта и запоминание положения закреплённого окна.
- **Нативное приложение.** SwiftUI и AppKit, запуск при входе в систему,
  работа в строке меню без иконки в Dock.

Направление перевода определяется автоматически. Интерфейс — на русском языке.

## Быстрый старт

### 1. Соберите приложение

Нужны **macOS 26+** и **Swift 6.2+**. Для сборки достаточно Command Line Tools;
отдельная установка Xcode не требуется. В проекте нет внешних Swift-зависимостей.

Если инструменты разработчика ещё не установлены:

```sh
xcode-select --install
```

Скачайте исходники и в каталоге проекта выполните:

```sh
make app
open build/Gloss.app
```

В строке меню появится иконка Gloss. Нажмите её правой кнопкой мыши,
чтобы открыть **«Настройки…»**.

### 2. Подготовьте перевод

В настройках на вкладке **«Перевод»** скачайте языковой пакет
английский ↔ русский. После загрузки обычный перевод работает офлайн.

Для словарных карточек дополнительно получите
[ключ Yandex Dictionary](https://yandex.ru/dev/dictionary/keys/get/?service=dict),
вставьте его на той же вкладке и нажмите **«Сохранить» → «Проверить»**.
Без ключа Gloss переводит слова через Apple Translation обычным текстом.

### 3. Переведите первый текст

Выделите слово или предложение в другом приложении и дважды нажмите **⌘C**.
При первом запросе macOS разрешите Gloss доступ к буферу обмена.

Для перевода с экрана нажмите **⌘⇧2** и выделите область. Для этой функции
потребуется разрешение на запись экрана; после его выдачи перезапустите Gloss.

<details>
<summary>Установка в Applications и автозапуск</summary>

Закройте запущенный Gloss через меню иконки → «Выход», затем выполните:

```sh
make install
open /Applications/Gloss.app
```

`make install` заменяет существующую копию `/Applications/Gloss.app`.
В настройках → «Основные» можно включить запуск при входе в систему.
Автозапуск доступен только для копии из `/Applications`.

Не запускайте одновременно копии из `build/` и `/Applications`: обе будут
реагировать на копирование текста.

</details>

## Управление

| Действие | Как вызвать |
| --- | --- |
| Перевести выделенный текст | Дважды **⌘C** |
| Перевести текст из буфера обмена | **⌘⇧1** |
| Распознать и перевести область экрана | **⌘⇧2** |
| Ввести текст вручную | Левый клик по иконке Gloss |
| Открыть настройки и меню | Правый клик или **Control + клик** по иконке |
| Перевести введённый текст | **Enter** |
| Добавить новую строку | **⇧Enter** или **⌥Enter** |
| Закрыть окно | **⌘W**; для незакреплённого окна также **Esc** |

Горячие клавиши и интервал двойного копирования меняются в настройках.
Если приложение не обновляет буфер при повторном ⌘C, используйте **⌘⇧1**.

Булавка в заголовке закрепляет окно; кнопка внизу копирует перевод.
Размер окна и высоту поля ввода можно менять перетаскиванием.
Подробности — в [руководстве](docs/guide.md#использование).

## Перевод и приватность

| Функция | Обработка данных |
| --- | --- |
| Словарь для слов и коротких фраз до трёх слов | Текст запроса отправляется в Yandex Dictionary, если настроен ключ |
| Перевод предложений и резервный перевод слов | Apple Translation на устройстве |
| Распознавание текста на экране | Apple Vision на устройстве |
| Хранение ключа Yandex | Связка ключей macOS (Keychain) |

Для двойного копирования Gloss отслеживает счётчик изменений буфера,
а сам текст читает после срабатывания. Разрешения «Универсальный доступ»
и «Мониторинг ввода» не нужны. Буфер с метками скрытого или временного
содержимого, которые используют менеджеры паролей, игнорируется.

Строки, похожие на пароли и токены, направляются в локальный переводчик
по эвристике. Ответы кешируются в памяти; текст запроса ограничен 5000 символами.

## Разработка

| Команда | Назначение |
| --- | --- |
| `make build` | Debug-сборка |
| `make test` | Тесты на Swift Testing |
| `make coverage` | Тесты и отчёт покрытия `GlossCore` |
| `make app` | Release-сборка и упаковка в `build/Gloss.app` |
| `make run` | Сборка и запуск приложения |
| `make install` | Сборка и установка в `/Applications` |
| `make clean` | Очистка артефактов сборки |

Запускайте тесты через `make`: Makefile настраивает путь к плагину
Swift Testing для Command Line Tools. Перед запуском новой сборки
закройте уже работающий Gloss.

```text
Sources/
├── Gloss/          # AppKit, SwiftUI, строка меню, окно перевода и настройки
└── GlossCore/      # Провайдеры перевода, буфер обмена, OCR и логика приложения
Tests/
└── GlossCoreTests/ # Тесты, фейки платформенных API и фикстуры
Resources/          # Иконки и Info.plist
scripts/            # Упаковка приложения и генерация иконок
```

Новый источник перевода добавляется через протокол `TranslationProvider`
и регистрируется в `AppEnvironment`. Результаты не зависят от провайдера,
поэтому менять интерфейс не требуется.

Подробности [архитектуры](docs/guide.md#архитектура),
[локальной подписи приложения](docs/guide.md#подпись-кода-codesign_identity)
и [особенностей Command Line Tools](docs/guide.md#особенности-command-line-tools)
описаны в руководстве. При сборке без стабильной подписи macOS может
повторно запросить доступ к Keychain и потребовать заново выдать разрешение
на запись экрана.

## Обратная связь

Для сообщения об ошибке создайте Issue: укажите версию macOS, шаги
воспроизведения, ожидаемый и фактический результат. Для ошибок сборки
приложите вывод `swift --version` и команды, которая завершилась ошибкой.
Не включайте API-ключи и личный текст в логи и скриншоты.
