# Gloss

Переводчик en↔ru в меню-баре macOS для изучения английского. Двойной Cmd+C в любом
приложении — и рядом с курсором появляется окно с переводом:

- для слова или короткой фразы (до 3 слов) — словарная карточка: транскрипция,
  части речи, варианты перевода, синонимы, примеры;
- для предложения — перевод текста.

Источники бесплатные: Yandex Dictionary API (словарь) и Apple Translation (перевод
предложений и запасной вариант, когда Yandex недоступен или не настроен).

## Требования

- macOS 26;
- Command Line Tools со Swift 6.2+ (`swift-tools-version:6.2`), Xcode не нужен:
  `xcode-select --install`;
- интернет — только для словаря Yandex; Apple Translation работает офлайн.

### Особенности Command Line Tools

- **Устаревшие `*.private.swiftinterface`.** В некоторых установках CLT остаются файлы
  от Swift 5.10, из-за которых любой `Package.swift` с `platforms` не собирается
  (`reference to member 'v15' cannot be resolved`). Лечится удалением:
  ```sh
  sudo rm /Library/Developer/CommandLineTools/usr/lib/swift/pm/ManifestAPI/PackageDescription.swiftmodule/*.private.swiftinterface \
          /Library/Developer/CommandLineTools/usr/lib/swift/pm/PluginAPI/PackagePlugin.swiftmodule/*.private.swiftinterface
  ```
- **Swift Testing.** Без Xcode `swift test` не находит плагин макросов
  (`plugin for module 'TestingMacros' not found`). `make test` и `make coverage` сами
  передают `-plugin-path` к `<toolchain>/usr/lib/swift/host/plugins/testing`, поэтому
  тесты запускаются только через `make`.
- **Нет плагина `SwiftUIMacros`.** Макрос `@State` недоступен, поэтому состояние вьюх
  объявляется как `private let x = State(initialValue: ...)` с доступом через
  `x.wrappedValue`. `@FocusState` и `@Bindable` работают как обычно.

## Сборка и запуск

| Команда         | Что делает                                                      |
|-----------------|-----------------------------------------------------------------|
| `make build`    | debug-сборка пакета                                             |
| `make test`     | unit-тесты (Swift Testing)                                      |
| `make coverage` | тесты с покрытием и отчёт `llvm-cov` по `Sources/GlossCore`     |
| `make app`      | release-сборка и упаковка в `build/Gloss.app` с подписью        |
| `make run`      | `make app` + запуск `build/Gloss.app`                           |
| `make install`  | `make app` + копия в `/Applications/Gloss.app`                  |
| `make clean`    | `swift package clean` (артефакты в `.build`) и удаление `build` |

Приложение живёт только в меню-баре (иконка с двумя облачками «A» и «Я»), в Dock его нет.

Иконки рисует скрипт `swift scripts/make-icons.swift`: он пересоздаёт
`Resources/AppIcon.icns` и `Resources/StatusIcon{,@2x}.png`, `make app` кладёт их в бандл.

Перед `make run` и `make install` закройте запущенный Gloss (меню трея → «Выход»):
`open` не перезапускает уже работающее приложение, а только активирует его со старым
бинарником. Не держите одновременно копии из `build/` и `/Applications`: обе следят
за буфером, и на двойной Cmd+C откроются два окна.

## Первичная настройка

### Ключ Yandex Dictionary

1. Войти с Яндекс ID и получить бесплатный ключ:
   <https://yandex.ru/dev/dictionary/keys/get/?service=dict>.
2. Правый клик по иконке в трее → «Настройки…» → вкладка «Перевод».
3. Вставить ключ, нажать «Сохранить», затем «Проверить».

Ключ хранится в Keychain (`service = com.dbashirov.gloss`, `account = yandex-dictionary`).
Без ключа слова переводятся через Apple Translation — без словарной карточки.

### Подпись кода (`CODESIGN_IDENTITY`)

Без стабильной подписи `.app` подписывается ad-hoc. У такой подписи designated
requirement - хеш бинарника, поэтому после каждой пересборки macOS считает приложение
новым: Keychain снова спрашивает доступ к ключу, а разрешение на запись экрана
перестаёт действовать (в настройках Gloss остаётся включённым, но не работает).
Стабильный self-signed сертификат это решает:

1. Создать сертификат `Gloss Local Signing` для подписи кода. Через «Связку ключей»:
   меню «Связка ключей» → «Ассистент сертификации» → «Создать сертификат…», тип
   удостоверения «Самоподписанный корневой», тип сертификата «Подписание кода».
   Или из терминала:
   ```sh
   cat > cert.cnf <<'CNF'
   [req]
   distinguished_name = dn
   x509_extensions = ext
   prompt = no
   [dn]
   CN = Gloss Local Signing
   [ext]
   basicConstraints = critical, CA:false
   keyUsage = critical, digitalSignature
   extendedKeyUsage = critical, codeSigning
   CNF
   openssl req -x509 -newkey rsa:2048 -nodes -days 3650 -config cert.cnf \
       -keyout key.pem -out cert.pem
   openssl pkcs12 -export -legacy -inkey key.pem -in cert.pem \
       -name "Gloss Local Signing" -out cert.p12 -passout pass:gloss
   security import cert.p12 -k ~/Library/Keychains/login.keychain-db -P gloss \
       -T /usr/bin/codesign
   rm key.pem cert.p12
   ```
2. Проверить, что сертификат виден: `security find-identity -p codesigning`.
3. `make app` сам подписывает сертификатом `Gloss Local Signing`, если он есть в связке
   ключей. Другой сертификат задаётся переменной `CODESIGN_IDENTITY`.
4. После смены подписи один раз: Keychain спросит доступ к ключу Yandex («Разрешать
   всегда»), а старое разрешение на запись экрана нужно сбросить
   (`tccutil reset ScreenCapture com.dbashirov.gloss`) и выдать заново.

### Доступ к буферу обмена

macOS спрашивает разрешение, когда приложение читает чужой буфер. При первом двойном
Cmd+C выберите «Разрешать всегда». Если доступ запрещён, окно покажет подсказку;
включить его можно в «Системные настройки → Конфиденциальность и безопасность →
Вставка из других приложений» (кнопка есть и в настройках Gloss).

### Доступ к записи экрана

Нужен для перевода текста с экрана: без него снимок приходит без содержимого окон.
При первом ⌘⇧2 macOS добавит Gloss в «Системные настройки → Конфиденциальность и
безопасность → Запись экрана и системного звука», а окно перевода покажет кнопку
«Разрешить запись экрана». Включите Gloss и перезапустите его. Статус и кнопка есть
в настройках Gloss, вкладка «Сочетания клавиш». С ad-hoc подписью разрешение приходится выдавать
заново после каждой пересборки - см. «Подпись кода».

### Языковой пакет en↔ru

Нужен Apple Translation. Настройки Gloss → «Перевод» → «Скачать» или
«Системные настройки → Основные → Язык и регион → Языки перевода» (английский и русский).

## Использование

- **Двойной Cmd+C** — перевод выделенного текста; окно появляется у курсора. Интервал
  между нажатиями настраивается (300–1000 мс, по умолчанию 500 мс); функцию можно
  выключить в меню трея или в настройках. Копирование из менеджеров паролей
  (`ConcealedType`/`TransientType`) игнорируется.
- **⌘⇧2 - перевод текста с экрана** (сочетание меняется в настройках): появляется прицел, как у системного ⌘⇧4, выделите
  мышью область с текстом (Esc - отмена). Текст распознаётся на устройстве (Apple Vision,
  английский и русский), подставляется в поле запроса и сразу переводится; ошибку
  распознавания можно поправить в поле и нажать Enter. Строки одного абзаца склеиваются
  в одну (перенос слова через дефис тоже), а абзацы остаются разделены пустой строкой:
  новый абзац узнаётся по промежутку между строками заметно шире обычного или по переходу
  в следующую колонку. Пункт списка (`-`, `•`, `*`) начинается с новой строки. Нужен
  доступ «Запись экрана» (см. ниже).
- **⌘⇧1 - перевод скопированного текста** (сочетание меняется в настройках): переводит
  то, что уже лежит в буфере обмена. Нужен там, где двойной Cmd+C не срабатывает:
  например, терминал с программой, которая сама выделяет текст мышью и копирует его
  (Claude Code в agterm/Ghostty), а Cmd+C после этого буфер не меняет. Если в буфере
  нет текста, откроется пустое окно для ручного ввода.
- **Левый клик по иконке** - окно с пустым полем для ручного ввода, Enter - перевести.
- **Правый клик (или Control+клик)** - меню: «Перевести текст с экрана», «Перевести
  скопированный текст», «Двойной Cmd+C», «Настройки…», «Выход».
- **Кнопки в заголовке окна** (названия — в подсказках при наведении):
  - «Закрепить» (булавка) — окно остаётся на экране, новые переводы появляются в нём же.
    Закрепление и позиция (верхний левый угол) переживают перезапуск; окно, закрытое
    кнопкой «Закрыть», при следующем переводе откроется закреплённым на прежнем месте;
  - «Закрыть» (крестик) или **Cmd+W** — закрыть окно в любом режиме.
- **Перетаскивание** - за любое место верхней полосы окна над полем запроса (кроме
  кнопок), и попапа, и закреплённого окна.
  Перетащенный попап перестаёт подстраиваться под курсор до следующего показа.
- **Размер окна** — потяните за край окна или за уголок-ручку справа внизу. Выбранный
  размер запоминается и переживает перезапуск, результат прокручивается внутри окна.
  Двойной клик по ручке возвращает автоматический размер «по содержимому».
- **Граница поля и перевода** - потяните полоску между полем запроса и переводом вверх
  или вниз: поле станет ниже или выше, перевод займёт остальное место. В окне, размер
  которого вы задали сами, полоска по умолчанию стоит посередине и запоминается как доля
  высоты: при растягивании окна по вертикали она сдвигается вместе с ним. В окне, которое
  подстраивается под содержимое, запоминается высота поля. Двойной клик по полоске
  возвращает положение по умолчанию: середину или высоту по тексту (3-6 строк).
- **Esc**, клик мимо окна или переключение на другое приложение закрывают попап
  (закреплённое окно — только кнопкой «Закрыть» или Cmd+W).
- «Произнести» (динамик) — озвучить слово; кнопка есть только в словарной карточке.
- «Копировать перевод» (две страницы) в футере — скопировать перевод; это копирование
  не запускает новый перевод.

### Как работает окно

- Скопированный текст стоит в поле запроса: его можно исправить и нажать Enter.
  Поле занимает от 3 до 6 строк (или высоту, выставленную полоской под ним), более
  длинный текст прокручивается полосой прокрутки справа; Enter - перевести,
  ⇧Enter (или ⌥Enter) - новая строка, чтобы разбить текст на абзацы.
- Лишние пробелы схлопываются, текст длиннее 5000 символов обрезается.
- Абзацы сохраняются: пустая строка остаётся пустой строкой, а перенос строки остаётся
  после конца предложения (`.`, `!`, `?`, `…`, `:`) и перед пунктом списка (`-`, `•`, `*`).
  Остальные переносы считаются переносом внутри предложения (текст из PDF, узкой колонки)
  и становятся пробелом. Каждый абзац переводится отдельно, поэтому перевод повторяет
  ту же разбивку, а предложение не разрывается.
- Ответы кешируются в памяти (500 запросов); смена ключа Yandex сбрасывает кеш.
- Ошибки показываются в окне с кнопкой действия, если его можно исправить: «Открыть
  настройки», «Скачать языковой пакет», «Разрешить доступ к буферу».
- Если словарь Yandex не ответил из-за неверного ключа, исчерпанного лимита или отказа
  Связки ключей, а Apple перевёл слово, над футером появится пометка о причине.
- Текст без букв и строки, похожие на пароли и токены (буквы с цифрами от 12 символов
  или от 8 при смешанном регистре, смена регистра внутри слова от 16 символов),
  не отправляются в Yandex и переводятся на устройстве через Apple Translation.

### Как срабатывает двойной Cmd+C

Gloss не перехватывает клавиши: раз в 100 мс он сравнивает `changeCount` буфера обмена,
поэтому разрешения «Универсальный доступ» и «Мониторинг ввода» не нужны. Срабатывают
любые два копирования в пределах интервала, не только Cmd+C; сам текст читается только
после срабатывания. Все изменения буфера за одну проверку считаются одним копированием:
некоторые приложения (например, Telegram) при одном Cmd+C меняют буфер дважды.

### Настройки

Правый клик по иконке → «Настройки…». Окно разбито на вкладки, высота окна подстраивается
под выбранную:

- **Основные** - запуск при входе в систему, двойной Cmd+C (вкл/выкл и интервал),
  статус доступа к буферу обмена с кнопкой перехода в системные настройки;
- **Оформление** - шрифт окна перевода (системный, скруглённый, с засечками,
  моноширинный или любое установленное семейство; удалённое из системы семейство
  заменяется системным) и его размер (11-20 pt, по умолчанию 14): от размера
  пропорционально меняются поле запроса, перевод, слово в карточке и подписи. Строка
  ниже показывает пример выбранного шрифта;
- **Сочетания клавиш** - горячие клавиши перевода текста с экрана (⌘⇧2) и скопированного
  текста (⌘⇧1): включение, сочетание и, для текста с экрана, статус доступа к записи
  экрана. Чтобы сменить сочетание, нажмите на него и введите новое (Esc - отмена,
  «Сбросить» возвращает сочетание по умолчанию). Нужны два модификатора, например ⌘⇧
  или ⌃⌥: одиночные ⌘ и ⌥ заняты командами приложений и вводом; F1-F20 можно назначить
  и без них. Две горячие клавиши Gloss не могут совпадать. Если сочетание занято другим
  приложением, настройки об этом скажут, а действие остаётся в меню иконки;
- **Перевод** - ключ Yandex: «Сохранить» записывает его в Связку ключей (пустое поле
  удаляет сохранённый ключ; если ключ не удалось прочитать, пустое поле сохранить
  нельзя), «Проверить» делает пробный запрос с введённым ключом без сохранения; статус
  языкового пакета английский ↔ русский и кнопка «Скачать».

### Запуск при входе в систему

Работает только для бандла из `/Applications`:

1. Закрыть запущенную копию (меню трея → «Выход»), `make install` (приложение
   не запускается само).
2. `open /Applications/Gloss.app`.
3. Настройки → «Основные» → «Запускать при входе в систему».

У копий из `build/` и `~/Applications` переключатель неактивен. Если macOS требует
подтверждения, кнопка «Открыть» ведёт в «Объекты входа».

## Архитектура

- `GlossCore` (library) — вся логика без AppKit/SwiftUI: модели, `TextNormalizer`,
  `QueryClassifier`, `Router` с кешем, провайдеры, `ClipboardWatcher` и
  `DoubleCopyDetector`, `TranslationController`, `AppSettings`, `PopupGeometry`,
  `ScreenTextReader` (выделение области → Vision → склейка строк).
  Платформенные API (HTTP, буфер, Keychain, Apple Translation, UserDefaults) скрыты
  за протоколами и в тестах подменяются фейками.
- `Gloss` (executable) - `AppDelegate`, трей, горячая клавиша (Carbon), захват области
  через `screencapture -i -s`, адаптер `NSPasteboard`, плавающая
  `NSPanel`, SwiftUI-вьюхи, окно настроек. Ресурсов в target нет.

Поток данных:

```
двойной Cmd+C / ручной ввод
  → TranslationController.translate      # отменяет предыдущий запрос
    → TextNormalizer → QueryClassifier    # язык en/ru, слово или предложение
    → Router (кеш → цепочка провайдеров)
  → state: idle | loading | result | failed → панель
```

**Точка расширения — `TranslationProvider`** (`id`, `supports(_:)`, `translate(_:)`).
Результат — `DictionaryEntry` или `TextTranslation`, не зависящие от источника. Новый
источник добавляется реализацией протокола и регистрацией в `AppEnvironment`;
UI менять не нужно.

**Фолбэк в `Router`.** Провайдеры опрашиваются по порядку (Yandex → Apple), на любую
`ProviderError` — переход к следующему. Если не ответил никто, возвращается самая
полезная ошибка: `invalidKey`/`rateLimited`/`languagePackMissing`/`keyUnavailable` >
`network`/`invalidResponse` > `notConfigured` > `notFound`. Кешируются
только результаты, полученные без ошибок предыдущих провайдеров; смена ключа сбрасывает
кеш.

## Планы

- `ClaudeProvider`: Claude Haiku 4.5 (модель в настройках), structured output →
  `DictionaryEntry`; кнопка «Разобрать» для предложений (грамматика, идиомы).
- Постоянный кеш в SQLite, история запросов, «мой словарь» и карточки для повторения.
- `FreeDictionaryProvider` (dictionaryapi.dev): английские определения, IPA, аудио.
- Горячая клавиша для окна ручного ввода и, при необходимости, `CGEventTap` для более
  надёжного двойного Cmd+C; своя комбинация для перевода с экрана.
